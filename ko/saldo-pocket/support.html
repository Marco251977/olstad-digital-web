자주 묻는 질문

무료와 Pro의 차이는 무엇인가요?

무료에는 예산, 「오늘 쓸 수 있는 돈」, 계좌 2개, 예산 1개, 저축 목표 1개, 직접 만든 카테고리 5개, 월 3회 스캔, 모든 데이터 내보내기가 포함됩니다. Pro는 최대 10개 계좌, 무제한 스캔·목표·카테고리, 자동으로 기록되는 고정 항목, 기간별 기록과 통계, Excel 및 CSV 보고서를 제공합니다. 가격은 App Store와 Google Play에 회원님의 통화로 표시됩니다.

새 휴대전화에서 구매를 복원하려면?

Pro는 Apple ID 또는 Google 계정에 연결됩니다. 새 휴대전화에서 같은 계정으로 로그인하고 Saldo Pocket을 열어 구매 복원을 누르세요. Pro 구매는 아직 열리지 않았으며, 열리면 이렇게 작동합니다.

데이터를 내보내려면?

내 정보 → 데이터 내보내기로 이동합니다. 내 모든 데이터 내보내기(JSON 또는 CSV)는 누구나 무료입니다. Pro에서는 기간과 계좌를 정해 보고서를 Excel 또는 CSV로 내보낼 수도 있습니다.

인터넷 뱅킹에서 가져오려면?

+를 누르고 인터넷 뱅킹에서 가져오기를 선택하세요. 목록의 스크린샷이나 사진, 또는 은행에서 내보낸 PDF·CSV·Excel 파일을 사용합니다. 저장하기 전에 모든 행을 확인하며, 이미 있는 행은 표시됩니다. Saldo Pocket은 절대 은행에 연결하지 않습니다.

데이터를 삭제하려면?

내 정보 → 모든 데이터 삭제로 이동합니다. 휴대전화에 있는 모든 것이 삭제됩니다. 자세한 내용은 데이터 삭제 페이지를 참고하세요.
